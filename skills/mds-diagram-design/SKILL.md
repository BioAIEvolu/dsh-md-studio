# mds-diagram 绘图规范

输出形式：```` ```mds-diagram <可选标题> ```` 围栏，内容为**一个完整的手写 SVG**。对话中也可直接输出裸 `<svg>` 代码块，渲染器同样识别。简单流程图继续用 mermaid 围栏。

## 一、色板（对比度已实测，别再自创）

节点用**浅色底 + 深色字**的软芯片（chip）配色——主题无关，深浅模式下可读性一致：

| 语义 | 底色 fill | 文字 fill | 强调/描边 | 实测对比度 |
|---|---|---|---|---|
| 主流程/核心 | `#B5D4F4` | `#0C447C` | `#85B7EB` | 6.42:1 |
| 警示/人工 | `#FAC775` | `#633806` | `#EF9F27` | 6.43:1 |
| 成功/通过 | `#9FE1CB` | `#085041` | `#5DCAA5` | 6.31:1 |
| 辅助/外部 | `#CECBF6` | `#3C3489` | `#AFA9EC` | 6.60:1 |
| 中性容器 | `var(--dsw-alias-bg-layer-2,#F6F8FA)` | `var(--dsw-alias-label-primary,#1F2937)` | `var(--dsw-alias-border-l1,#D0D7DE)` | 随主题 |

规则：

- 一个图**最多 4 种语义色**，超过时先合并语义而不是加颜色。
- 用了 ≥3 种颜色时，**必须有图例**（色块 12×12 rx=3 + 12px 文字，置于图顶部）。
- **浅色芯片只配上表里的深色字。** 白字压 `#B5D4F4` 只有 **1.53:1**、压 `#9FE1CB` 只有 1.49:1——这就是"底色和文字都太浅看不清"的唯一来源，**禁止**。深色底才用浅色字（`#1F6FEB` + 白字 = 4.63:1 可以，`#B5D4F4` + 白字不行）。
- **不要自创浅色组合**（例如 `#DCEBFB` 底 + `#7FA8D9` 字，只有 1.4:1）。需要第 5 种颜色时，换语义或加分组，不加颜色。
- 文字**不透明度 ≥ 0.85**：`opacity="0.8"` 就把 6.42:1 掉到 4.21:1，`0.7` 只剩 3.43:1。副标题要弱化就用字号/字重，不用透明度硬压。
- 深色底上的辅助字同样要 ≥4.5:1，宁可换白字也不要灰字。

## 二、每个 `<text>` 自己带 `fill`（最容易被忽略）

压在色块上的文字，**必须在 `<text>` 元素上写出处字色**：

```xml
<!-- 正例：字色写死在 text 上，导出到任何工具都稳定 -->
<rect x="24" y="60" width="150" height="56" rx="8" fill="#B5D4F4"/>
<text x="99" y="84" fill="#0C447C">接入层</text>
```

```xml
<!-- 反例：底浅、字没写 fill → 渲染器兜底/深色主题白字 → 白底白字，1.3:1 -->
<rect x="24" y="60" width="150" height="56" rx="8" fill="#B5D4F4"/>
<text x="99" y="84">接入层</text>
```

- 允许在同一个节点的组里用 `<g fill="#0C447C">` 复用，但**不要依赖主题默认值**，也不要把字色写成 `fill="white"`/`#fff` 之后又压浅色底。
- 画布级文字（下方没有色块）是唯一允许用主题变量的地方，见第三节。

**交付前跑一次检查脚本**（零依赖，报错即改）：

```bash
node skills/mds-diagram-design/scripts/check-svg-contrast.mjs 你的图.svg
```

它会按色块几何位置算 WCAG 对比度，输出 `< 4.5:1` 的具体条目与字号建议；`--self-test` 是脚本自带用例。

> dsh-md-studio ≥ 1.3.13 在渲染时也会做一次兜底：把看不清的文字改成"同色相深墨"并抬回不透明度。**但这只是安全网**——兜底色不一定是你要的语义色，也会改动你的 opacity，所以按规范写，不要依赖它。

## 三、画布级文字（深色模式的关键）

直接画在透明底上的文字（图例、分组标签、注解），**必须**用主题变量，禁止硬编码深灰：

```xml
<text style="fill:var(--dsw-alias-label-primary,#1F2937)" font-size="12">图例</text>
```

这样文字会随 DSH 深浅主题自动翻转。硬编码 `#1F2937` 在深色模式下会不可见；反过来，色块**内部**的文字不要用主题变量，否则浅色主题下白底白字。

## 四、字体阶

- 主标题/图标题：14–15px / 500
- 副标题/正文：13px / 400
- 图例/标签/注解：12px / 400

字体族：`system-ui, sans-serif`（根元素统一设置，子元素继承）。每张图在 `<svg>` 内放一个 `<title>` 描述用途（渲染为卡片标题）。

## 五、布局

- WorkBuddy 风格推荐画布基准宽度 680px：`viewBox="0 0 680 H"`；内容限制在 x=40–640，按元素实际底边计算 H，顶部和底部各留 ≥20px。图宽按 SVG viewBox 保持原始字号，窄面板可横向滚动并提供"适应宽度"和全屏查看，避免为了塞进面板而把标签缩小。
- 每张图优先选单方向流程，节点总数控制在 4–8 个；超出时按职责拆成多图或折叠为分组，不通过加宽画布或缩小字体容纳。复杂架构允许例外，但默认结构化纵向分层，减少横向连线交叉。
- 中文文本按实际字宽估算和试排（中文通常接近一个字号的宽度），不能直接套英文字母字符估宽；长标签换行或拆为主副标题。

## 六、关系表达（关系明确）

- 箭头：`<defs>` 里定义一次 `<marker>`（id 加随机后缀防冲突），所有指向性连线共用。
- 线型语义：**实线 = 同步/强依赖，虚线（stroke-dasharray="6 4"）= 异步/可选，粗线 = 数据流，细线 = 控制流**。
- 每条语义不明显的连线加 12px 线上标签；纯结构连线可省。
- 分组/分层容器：themed 底色 + 1px 描边 + 左上角 12px 分组标签，组内成员缩进 ≥16px。
- 顺序步骤用编号圆徽：圆直径 24，底色用**深色**（如 `#1F6FEB`）配白字，或浅色芯片配该芯片的深色字；**不要**用浅色芯片底 + 白字（1.5:1）。

## 七、输出前自查清单

1. viewBox 与实际内容贴合，没有大片空白？
2. **每段文字都能说出它的底色是什么？代入对比度 ≥4.5:1？**（浅底绝不配白字/浅字）
3. 色块上的每个 `<text>` 都自带 `fill`，没有依赖 `<g>`/主题默认？
4. 画布级文字用了 `var(--dsw-alias-label-primary,…)`，色块内文字**没有**用它？
5. 文字 opacity ≥0.85？没有用透明度硬压成"灰字"？
6. ≥3 种颜色时有图例？颜色只用调色板 4 组？
7. 连线都有箭头或明确语义？虚线/实线用法一致？
8. 同类节点对齐、等宽？文字都没有溢出？
9. `<title>` 已写？marker id 无冲突？单图节点 ≤12？
10. 跑过 `check-svg-contrast.mjs` 且退出码为 0？（无 Node 环境时人工核对 1–5 条）

**示例骨架**：

```xml
<svg viewBox="0 0 640 210" width="100%" font-family="system-ui,sans-serif">
  <title>请求处理流程</title>
  <defs>
    <marker id="arr-a1" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="7" markerHeight="7" orient="auto-start-reverse">
      <path d="M0,0 L10,5 L0,10 Z" fill="#85B7EB"/>
    </marker>
  </defs>
  <!-- 图例（画布级文字 → 主题变量） -->
  <rect x="24" y="16" width="12" height="12" rx="3" fill="#B5D4F4"/>
  <text x="42" y="26" font-size="12" style="fill:var(--dsw-alias-label-primary,#1F2937)">核心流程</text>
  <!-- 节点（浅底 + 同色相深色字，字色写在 text 上） -->
  <rect x="24" y="60" width="150" height="56" rx="8" fill="#B5D4F4"/>
  <text x="99" y="84" font-size="14" font-weight="700" text-anchor="middle" fill="#0C447C">接入层</text>
  <text x="99" y="102" font-size="12" text-anchor="middle" fill="#0C447C" opacity="0.85">校验与路由</text>
  <!-- 连线 -->
  <line x1="174" y1="88" x2="226" y2="88" stroke="#85B7EB" stroke-width="2" marker-end="url(#arr-a1)"/>
  <!-- 深色底才配白字 -->
  <rect x="226" y="60" width="150" height="56" rx="8" fill="#1F6FEB"/>
  <text x="301" y="92" font-size="14" text-anchor="middle" fill="#FFFFFF">网关</text>
</svg>
```
